Ex01 : Processus d’affichage d’une page statique.

  1. Le navigateur envoie une requête HTTP, par exemple GET /ex01/affichage, au serveur de développement lancé par python manage.py runserver.
  2. Django crée un objet HttpRequest et le fait passer par les middlewares.
  3. Le résolveur consulte d04/urls.py, puis les routes de l’application ex01/urls.py, pour trouver la vue correspondant exactement au chemin.
  4. La vue reçoit la requête et appelle render(request, "ex01/affichage.html"). Le chargeur trouve le template dans le dossier templates de l’application.
  5. Le moteur de templates applique l’héritage et les inclusions, puis remplace les variables par les valeurs du contexte. Le résultat est une chaîne de HTML.
  6. render construit une HttpResponse. Les middlewares de réponse interviennent et le serveur renvoie le HTML avec le statut HTTP 200.
  7. Le navigateur analyse le document, demande la feuille CSS indiquée par son lien et affiche la page. Son contenu est statique, même si Django produit la réponse à chaque requête.

Si aucune route ne correspond, Django répond avec le statut 404.

Source : raccourcis HTTP de Django.
