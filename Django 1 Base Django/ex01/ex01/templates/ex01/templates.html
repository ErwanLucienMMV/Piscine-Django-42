Ex01 : Moteur de template.

Le moteur Django transforme un fichier texte en document final. La vue fournit un contexte : un dictionnaire dont les clés deviennent les noms disponibles dans le template. Le moteur résout les variables, évalue les balises et assemble les templates.

Blocs et héritage

Un parent définit des emplacements nommés avec block. Un enfant utilise extends en première balise et remplace les blocs souhaités ; les autres gardent leur contenu parent. include insère un fragment comme notre navigation.

{% verbatim %}{% extends "ex01/base.html" %}
{% block title %}Mon titre{% endblock %}
{% block content %}<p>Mon texte</p>{% endblock %}{% endverbatim %}

Boucles for … in

for parcourt une collection ; empty traite une collection vide. forloop.counter donne le numéro de l’itération, à partir de 1.

{% verbatim %}{% for topic in topics %}
    {{ forloop.counter }}. {{ topic }}
{% empty %}
    Aucun sujet.
{% endfor %}{% endverbatim %}
    {% for topic in topics %}
  • {{ forloop.counter }}. {{ topic }}
    • {% empty %}
  • Aucun sujet.
    • {% endfor %}

Conditions if

if, elif et else choisissent un contenu selon une valeur, une comparaison ou des opérateurs comme and, or et not.

{% verbatim %}{% if show_example %}Exemple visible.{% else %}Exemple masqué.{% endif %}{% endverbatim %}
{% if show_example %}

Exemple visible.

{% else %}

Exemple masqué.

{% endif %}

Variables et filtres

Les doubles accolades affichent une valeur ; la notation pointée accède à une clé ou un attribut. Un filtre modifie sa présentation. Le HTML des valeurs est échappé par défaut pour protéger la page.

{% verbatim %}Bonjour {{ visitor }} !
{{ visitor|upper }}{% endverbatim %}

Bonjour {{ visitor }} ! En majuscules : {{ visitor|upper }}.
