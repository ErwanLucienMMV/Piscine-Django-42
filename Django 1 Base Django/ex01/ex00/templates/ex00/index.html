Ex00 : Markdown Cheatsheet.

Markdown permet de structurer un texte avec des signes simples. Voici la syntaxe de base, puis les extensions courantes : leur disponibilité dépend du moteur utilisé.

Syntaxe Markdown de base
ÉlémentSyntaxeEffet et remarques
Titres ATX
# Titre 1
## Titre 2
### Titre 3
#### Titre 4
##### Titre 5
###### Titre 6
Six niveaux de titres ; séparer le marqueur du titre par une espace.
Titres Setext
Grand titre
===========
Sous-titre
----------
Les signes = et - soulignent les titres de niveaux 1 et 2.
Paragraphes et sauts
Un paragraphe.

Un autre paragraphe.
Une ligne suivie de deux espaces.  
La ligne suivante.
Une ligne vide sépare les paragraphes. Deux espaces en fin de ligne produisent un saut de ligne ; CommonMark accepte aussi un antislash final.
Emphase*léger* ou _léger_
**fort** ou __fort__
***les deux***		Italique, gras, gras et italique.
Citation
> Une citation
>
> > Une citation imbriquée
Les citations peuvent contenir d’autres blocs, dont des listes.
Liste non ordonnée
- Thé
- Café
  - Décaféiné
Les marqueurs *, + et - sont possibles. Indenter les sous-listes sous le contenu parent.
Liste ordonnée
1. Préparer
2. Servir
Une liste numérotée. CommonMark accepte aussi 1). Une ligne vide permet plusieurs paragraphes dans un élément.
Code en ligne`print("bonjour")`
``un ` dans du code``		Les accents graves protègent les caractères de formatage.
Bloc de code indenté
    def saluer():
        return "Bonjour"
Quatre espaces d’indentation créent un bloc de code.
Bloc de code délimité
```python
print("Bonjour")
```
En CommonMark : au moins trois accents graves ou tildes ; le langage est facultatif.

Trois astérisques, tirets ou traits de soulignement forment une séparation. Isoler le bloc pour éviter un titre Setext.
Lien direct[Documentation](https://docs.djangoproject.com/ "Django")Texte cliquable, URL et titre facultatif entre guillemets.

HTML et entités<sup>2</sup>
